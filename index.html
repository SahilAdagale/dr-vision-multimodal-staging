How it works:

The deferral system uses contrastive learning trained on synthetically degraded images (blurred, rotated, poorly lit) to detect unreliable inputs. When the model's confidence falls below the threshold, the case is automatically routed to an ophthalmologist instead of returning an automated diagnosis — preventing silent misdiagnosis.
